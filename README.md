# Sagar Patil — Portfolio

Personal portfolio site. Plain HTML/CSS/JS, no build step.

## Deploy on GitHub Pages
1. Create a repo named `<your-github-username>.github.io`
2. Upload `index.html`, `profile.jpg` and `moksha-icon.png` to the repo root
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save
4. Live in ~1 minute at `https://<your-github-username>.github.io`
